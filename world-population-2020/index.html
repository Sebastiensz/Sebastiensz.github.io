Population mondiale en 2020

Estimation du dénombrement de la population mondiale pour 2020 sous forme de grille d'environ 110 km de résolution. La hauteur de chaque cube traduit le nombre d'habitants de la cellule. Utilisez le curseur pour filtrer les cellules selon le nombre de personnes par cellule. Seules les cellules de plus de 10 personnes sont affichées.

Chargement du globe…

Données raster de population d'origine de SEDAC (GPW v4, CIESIN / NASA). Frontières et graticule : Esri, Garmin, CIA World Factbook, National Geographic. Ce prototype a été réalisé avec l'ArcGIS API for JavaScript. Le code de cette application : Github.
